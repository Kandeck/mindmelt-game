# 脑裂 · MINDMELT 🧠💥

一款**会进化、会反套你**的反应力小游戏。看指令点目标，连对得分——但游戏越玩越坏：
每撑久一点，它就叠加新规则、裂开屏幕、甚至开始学习并反套你的点击习惯。你的大脑能撑到第几阶段？

**▶️ 在线试玩：https://mindmelt-game.pages.dev**

## 四个进化阶段

1. **直觉** — 正常点：指令让你点什么颜色就点什么。
2. **雪球** — 规则永久叠加且同时生效：「看字不看色」→「带黑框的点对角」→「闪烁的点顺时针下一个」……到后面你要同时遵守好几条互相打架的规则。
3. **脑裂** — 屏幕裂成左右两半，两只手同时执行互相矛盾的指令。
4. **背叛** — 目标开始学习你的习惯：你总点某个位置，正确答案就悄悄躲开它。它在读你的心。

死亡后可立即重开，"不服再来"。

## 病毒传播设计

- 死亡结算生成可复制的战绩文案 + 挑战链接（带成绩参数 `?s=&st=&n=`）。
- 好友点开链接，开屏与结算即显示「好友挑战 连对X·第Y阶段」并实时比分。
- `localStorage` 记录个人最佳（最高连对 / 最远阶段），制造自我挑战。
- 移动端优先，一指可玩，打开即玩。

## 技术

- **单文件 `index.html`**，纯静态、零依赖、零构建、无后端、无密钥。
- Canvas 2D 绘制神经元背景，游戏逻辑为原生 JS。
- 核心是一个「规则栈判定引擎」：出题时按规则栈依次计算唯一正确目标；阶段进化 = 往规则栈加规则 / 开启分屏 / 开启习惯反套。判定引擎经 8 万次不变量测试（显示的正确目标 == 判定结果，零偏差）。
- 所有视觉均为**原创几何/抽象图形**，不含任何图片素材或受版权保护的角色。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署（Cloudflare Pages，纯静态免费）

1. GitHub 建空仓库，推送本项目。
2. Cloudflare Pages → Create → Continue to Pages → Connect to Git → 选本仓库。
3. Framework preset = None，Build command 留空，Build output directory = `/`。
4. Deploy，拿到 `xxx.pages.dev` 即可分享。**无需任何环境变量。**
